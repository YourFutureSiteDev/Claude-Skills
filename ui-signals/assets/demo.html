Signal 01 · Drag feedback

Nothing reacts. It has to answer back.

Three signals before the drop: border, glow, copy. Drag any file over the box.

Belongs on: a file dropzone. Never on: anything that is not one.

Signal 02 · Honest progress

A spinner hides the truth.

Percent, time left, rate. The user decides whether to wait or walk away.

Belongs on: an operation over one second with a measurable length. Unknown length: use the skeleton instead.

Signal 03 · Inline retry

It dies at ninety percent.

The bar turns red where it stopped, the error grows in with a Retry, the file stays. Retry resumes from 90%. Never make them start over.

Belongs on: any network action that can fail. Never on: actions that cannot fail.

Signals 06 to 09 · Forms

Press, focus, submit, error.

Press is 120ms scale to 0.97. Focus is a ring, not an outline removal. Submit locks its width and moves through loading, done or error. A field error grows under that field only.

Press: buttons only. Focus: text inputs only. Submit states: the form's submit button only. Field error: the one invalid field, never the whole form.

Signals 10 to 12 · State

Copy swap, one glow, the tick.

Copy crossfades when a label changes with state. The glow marks the single live element on the page, and moves rather than multiplies. The tick draws itself only on success.

Glow: exactly one element at a time. Tick: success states only, never neutral or error.

Signals 13 to 18 · Page

Toast, chips, reveal, lift.

This section revealed on scroll because it is below the fold. The hero at the top did not, and would be refused. The headline emphasis ran once on load. The nav underline is at the top.

Reveal: below-fold sections only. Chips: tag lists entering view, once. Card lift: cards that link somewhere, hover-gated. Toast: transient messages only.

Signals 19 and 20 · Numbers and loading

Count up, and skeleton.

Stats count from zero once, when they enter view. Skeletons stand in for content that arrives after first paint, and never for content already in the HTML.

Count-up: a stats section. Never: prices in a checkout, table cells. Skeleton: async content only.
