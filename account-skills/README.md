# Account skills (backup copy)

These 14 skills come from your Claude account, not from this folder. Claude
downloads them itself on any machine you sign in to, so you do not need to
install them from here.

They are nested one level down on purpose: Claude only loads
`~/.claude/skills/<name>/SKILL.md`, so nothing in here is picked up twice.

This copy exists as a backup and so you can read or edit the source. The ones
you wrote yourself are `chatgpt-photos` and `no-em-dashes` — edit those on
claude.ai, not here, or your changes will be overwritten by the account copy.
